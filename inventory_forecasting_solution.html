Krystal Ball: Hotel Bar Inventory Forecasting & Par Level Recommendation System¶

Goal. Turn bottle-level transaction logs from multiple hotel bars into daily consumption series, forecast future demand, calculate a dynamic Par Level (reorder target) per bar/brand, and backtest that policy against a naive baseline via a discrete-event inventory simulation.

Notebook sections

  1. Data Understanding & Preprocessing
  2. Exploratory Data Analysis (ABC classification, seasonality, stockout audit)
  3. Demand Forecasting (Baseline vs Holt-Winters vs Random Forest)
  4. Par Level & Safety Stock Calculation
  5. Inventory Simulation Engine (Naive vs Recommended policy)
  6. Findings & Recommendations

Note on the data. No transaction log was supplied with this assignment brief, so this notebook generates a realistic synthetic dataset that matches the required schema (Date Time Served, Bar Name, Brand Name, Opening Balance, Purchase, Consumed, Closing Balance) across 4 bars x 10 brands x 210 days, with weekly seasonality, a mild upward trend, and intermittent slow-movers. To use real data, drop your own bar_inventory_data.csv into data/raw/ with the same column names and skip the "Generate synthetic data" cell — everything downstream is written generically and will run unchanged on real transaction logs with that schema.

0. Generate synthetic data (skip this cell if you have a real bar_inventory_data.csv)¶

Simulates realistic bottle-ledger transactions: pours throughout the evening (weighted randomly to sum to a day's total demand, itself driven by weekday/weekend seasonality, a mild upward trend, and per-brand "velocity"), plus periodic supplier deliveries. Every row is constructed to satisfy the inventory conservation identity:

Closing Balance = Opening Balance + Purchase − Consumed

rng = np.random.default_rng(42)

BARS = {
    "Skyline Rooftop Bar": 1.35,
    "Poolside Bar":        1.10,
    "Lobby Lounge Bar":    0.80,
    "Sports Bar":          1.00,
}

# brand -> (velocity class, base daily mean ml, restock qty ml, restock cycle days)
BRANDS = {
    "Grey Goose Vodka":      ("A", 2600, 12000, 2),
    "Absolut Vodka":         ("A", 2200, 12000, 2),
    "Jack Daniel's Whiskey": ("A", 2400, 12000, 2),
    "Johnnie Walker Black":  ("B", 1400,  9000, 3),
    "Bacardi Rum":           ("B", 1100,  9000, 3),
    "Jose Cuervo Tequila":   ("B",  900,  9000, 3),
    "Heineken Beer":         ("A", 3000, 15000, 2),
    "Corona Beer":           ("A", 2800, 15000, 2),
    "Aperol":                ("C",  350,  6000, 5),
    "Campari":               ("C",  300,  6000, 5),
}

from datetime import datetime, timedelta
START_DATE, N_DAYS = datetime(2025, 1, 1), 210
rows = []

for bar, bar_mult in BARS.items():
    for brand, (velocity, base_mean, restock_qty, restock_cycle) in BRANDS.items():
        stock = restock_qty * 1.5
        next_restock_offset = int(rng.integers(0, restock_cycle))

        for day_idx in range(N_DAYS):
            date = START_DATE + timedelta(days=day_idx)
            dow = date.weekday()
            dow_factor = {0: 0.75, 1: 0.80, 2: 0.90, 3: 1.05, 4: 1.45, 5: 1.55, 6: 1.15}[dow]
            trend_factor = 1.0 + 0.15 * (day_idx / N_DAYS)

            sell_today = not (velocity == "C" and rng.random() < 0.35)
            daily_mean = base_mean * bar_mult * dow_factor * trend_factor
            daily_demand = max(0.0, rng.normal(daily_mean, daily_mean * 0.25)) if sell_today else 0.0

            if day_idx == 0 or (day_idx - next_restock_offset) % restock_cycle == 0:
                purchase_today = restock_qty * rng.uniform(0.9, 1.1)
                ts = date.replace(hour=10, minute=int(rng.integers(0, 59)))
                opening = stock
                closing = opening + purchase_today
                rows.append({"Date Time Served": ts, "Bar Name": bar, "Brand Name": brand,
                             "Opening Balance (ml)": round(opening, 1), "Purchase (ml)": round(purchase_today, 1),
                             "Consumed (ml)": 0.0, "Closing Balance (ml)": round(closing, 1)})
                stock = closing

            if daily_demand > 0:
                n_tx = int(rng.integers(3, 14))
                weights = rng.dirichlet(np.ones(n_tx))
                pour_amounts = np.round(daily_demand * weights, 1)
                hours = np.sort(rng.uniform(11, 23.98, size=n_tx))
                for pour_ml, hr in zip(pour_amounts, hours):
                    h, m = int(hr), int((hr - int(hr)) * 60)
                    ts = date.replace(hour=min(h, 23), minute=min(m, 59))
                    opening = stock
                    actual_consumed = min(pour_ml, opening)
                    closing = opening - actual_consumed
                    rows.append({"Date Time Served": ts, "Bar Name": bar, "Brand Name": brand,
                                 "Opening Balance (ml)": round(opening, 1), "Purchase (ml)": 0.0,
                                 "Consumed (ml)": round(actual_consumed, 1), "Closing Balance (ml)": round(closing, 1)})
                    stock = closing

synthetic_df = pd.DataFrame(rows).sort_values(["Bar Name", "Brand Name", "Date Time Served"]).reset_index(drop=True)
synthetic_df.to_csv(RAW_PATH, index=False)

3. Demand Forecasting¶

For every Bar x Brand series we fit three candidate models on a temporal 80/20 train/test split (never a randomized k-fold on time series) and keep the best by WAPE:

  • Baseline — 7-day trailing rolling mean (a naive seasonal-ish baseline)
  • Holt-Winters — additive exponential smoothing with a 7-day seasonal period
  • Random Forest — lag (t-1, t-7, t-14), rolling mean/std, and day-of-week features

WAPE (sum(|y - y_hat|) / sum(y)) is used instead of MAPE because MAPE divides by individual actuals and blows up on the many zero-demand days in this intermittent data.

In [8]:
def make_features(series_df):
    s = series_df.sort_values("Date").reset_index(drop=True)
    s["lag_1"]  = s["Consumed (ml)"].shift(1)
    s["lag_7"]  = s["Consumed (ml)"].shift(7)
    s["lag_14"] = s["Consumed (ml)"].shift(14)
    s["rolling_mean_7"] = s["Consumed (ml)"].shift(1).rolling(7).mean()
    s["rolling_std_7"]  = s["Consumed (ml)"].shift(1).rolling(7).std()
    s["dayofweek"] = s["Date"].dt.dayofweek
    s["is_weekend"] = s["dayofweek"].isin([4, 5, 6]).astype(int)
    return s

def wape(y_true, y_pred):
    y_true, y_pred = np.asarray(y_true), np.asarray(y_pred)
    denom = np.sum(np.abs(y_true))
    return np.sum(np.abs(y_true - y_pred)) / denom if denom > 0 else np.nan

def mae(y_true, y_pred):
    return np.mean(np.abs(np.asarray(y_true) - np.asarray(y_pred)))

FEATURE_COLS = ["lag_1", "lag_7", "lag_14", "rolling_mean_7", "rolling_std_7", "dayofweek", "is_weekend"]

results, forecast_store = [], {}

for (bar, brand), g in daily_ts.groupby(["Bar Name", "Brand Name"]):
    s = make_features(g)
    split = int(len(s) * 0.8)
    train, test = s.iloc[:split], s.iloc[split:]
    y_train, y_test = train["Consumed (ml)"].values, test["Consumed (ml)"].values

    # Baseline: lagged 7-day rolling mean (no leakage)
    baseline_pred = test["rolling_mean_7"].fillna(train["Consumed (ml)"].mean()).values
    baseline_wape = wape(y_test, baseline_pred)

    # Holt-Winters, weekly seasonality
    try:
        hw_fit = ExponentialSmoothing(y_train + 1e-3, trend=None, seasonal="add",
                                       seasonal_periods=7, initialization_method="estimated").fit(optimized=True)
        hw_pred = np.clip(hw_fit.forecast(len(y_test)), 0, None)
    except Exception:
        hw_pred = np.full(len(y_test), y_train.mean())
    hw_wape = wape(y_test, hw_pred)

    # Random Forest on lag/rolling/calendar features
    train_f, test_f = train.dropna(subset=FEATURE_COLS), test.dropna(subset=FEATURE_COLS)
    rf_pred = np.full(len(y_test), y_train.mean())
    if len(train_f) > 20 and len(test_f) > 0:
        rf = RandomForestRegressor(n_estimators=200, max_depth=8, random_state=42, n_jobs=-1)
        rf.fit(train_f[FEATURE_COLS], train_f["Consumed (ml)"])
        mask = np.isin(test.index, test_f.index)
        rf_pred[mask] = np.clip(rf.predict(test_f[FEATURE_COLS]), 0, None)
    rf_wape = wape(y_test, rf_pred)

    candidates = {"Baseline_RollingMean": (baseline_wape, baseline_pred),
                  "HoltWinters": (hw_wape, hw_pred),
                  "RandomForest": (rf_wape, rf_pred)}
    best_name = min(candidates, key=lambda k: candidates[k][0])
    best_wape, best_pred = candidates[best_name]
    best_mae = mae(y_test, best_pred)
    residual_std = np.std(y_test - best_pred) if len(y_test) > 1 else np.std(y_train)

    results.append({"Bar Name": bar, "Brand Name": brand,
                     "Baseline_WAPE": baseline_wape, "HoltWinters_WAPE": hw_wape, "RandomForest_WAPE": rf_wape,
                     "Best_Model": best_name, "Best_MAE": best_mae, "Best_WAPE": best_wape,
                     "Forecast_Daily_Demand": float(np.mean(best_pred)), "Residual_Std": float(residual_std)})
    forecast_store[(bar, brand)] = {"test_dates": test["Date"].values, "actual": y_test, "pred": best_pred}

4. Par Level & Safety Stock Calculation¶

Par Level = Lead-Time Demand + Safety Stock, where Safety Stock buffers against demand volatility during the supplier lead time L:

Safety Stock = Z * sigma_L, with sigma_L = residual_std * sqrt(L)

  • L = supplier lead time in days (2 days here)
  • Z = service-level factor (1.645 for 95%, 2.326 for 99%)
In [11]:
def compute_par_level(predicted_daily_demand, std_daily_demand, lead_time_days=2, service_level_z=1.645):
    lead_time_demand = predicted_daily_demand * lead_time_days
    safety_stock = service_level_z * (std_daily_demand * np.sqrt(lead_time_days))
    return lead_time_demand + safety_stock, safety_stock

5. Inventory Simulation Engine¶

A discrete daily order-up-to-Par simulation, backtested on the actual held-out demand for each series. We compare two policies:

  • Naive — order up to mean demand x lead time with no safety stock
  • Recommended — order up to the Section 4 Par_Level_ml (lead-time demand + safety stock)
In [12]:
def simulate_bar_inventory(actual_demand, par_level, lead_time=2, initial_stock=None):
    if initial_stock is None:
        initial_stock = par_level
    stock, stockouts, lost_volume, pending_orders, history = initial_stock, 0, 0.0, [], []

    for demand in actual_demand:
        for order in pending_orders:
            order[0] -= 1
        arrived = [o for o in pending_orders if o[0] <= 0]
        stock += sum(o[1] for o in arrived)
        pending_orders = [o for o in pending_orders if o[0] > 0]

        if stock >= demand:
            stock -= demand
        else:
            lost_volume += (demand - stock)
            stockouts += 1
            stock = 0

        effective_inventory = stock + sum(o[1] for o in pending_orders)
        if effective_inventory < par_level:
            pending_orders.append([lead_time, par_level - effective_inventory])

        history.append(stock)

    return {"stockout_days": stockouts, "stockout_rate": stockouts / len(actual_demand),
            "lost_volume_ml": lost_volume, "average_inventory_ml": float(np.mean(history)),
            "history": history}

6. Findings & Recommendations¶

  • Best model choice varies by series but Holt-Winters (weekly seasonality) wins most often, reflecting the strong Friday/Saturday demand pattern observed in Section 2; Random Forest is competitive on the highest-volume Class A items with more stable lag structure.
  • The recommended dynamic Par Level policy materially reduces stockouts versus a naive "mean demand x lead time" policy, at the cost of holding more average inventory — the classic service-level/holding-cost trade-off, tunable via the SERVICE_Z parameter (raise to 2.326 for a 99% service level on Class A items only, to avoid over-provisioning Class C tails).
  • Recommended next steps for production: promotional-calendar awareness, live POS event triggers instead of a daily batch job, joint vendor delivery consolidation across nearby bars, and continuous drift monitoring (forecast MAE vs. realized orders) with automatic model refresh.
